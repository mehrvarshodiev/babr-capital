# Babr Capital

Premium corporate fintech website rebuilt with React, TypeScript, Vite, Tailwind CSS and React Router.

## Stack
- React + TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Lucide React
- Git/GitHub

## Features
- Tajik / Russian language switcher with localStorage persistence
- Dark / light theme with localStorage persistence
- Responsive navigation and mobile menu
- Smooth section navigation
- Responsive fintech corporate UI
- Client-side application form validation and success/error states
- Accessible labels, buttons and focus states

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
