# Babr Capital — Glassmorphism Frontend

Файли асосӣ: `index.html`

## Иҷро
1. ZIP-ро кушоед.
2. `index.html`-ро дар браузер кушоед.
3. Tailwind CSS аз CDN бор мешавад, бинобар ин барои preview server ҳатмӣ нест.

## Функсияҳо
- Responsive mobile-first layout
- Glassmorphism UI
- Sticky navigation + smooth scrolling
- Mobile hamburger menu
- TJ 🇹🇯 / RU 🇷🇺 language switcher
- Dark / Light mode
- Online application validation + simulated success
- Hover/glow effects
- Телефон ва email дар footer

Барои production-и пурра метавонед Tailwind CDN-ро ба build-и Tailwind/Vite иваз кунед ва form-ро ба backend/API пайваст намоед.
