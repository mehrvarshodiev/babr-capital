# 🐅 Babr Capital — Corporate Website

A modern, premium and fully responsive corporate website for **Babr Capital**, a financial institution in Tajikistan.

Built with **HTML5, Tailwind CSS and Vanilla JavaScript**, with a strong focus on performance, accessibility, responsive design and modern financial UI/UX.

## ✨ Features

- 🌐 **Bilingual support** — Tajik 🇹🇯 / Russian 🇷🇺
- 🌙 **Dark / Light theme**
- 📱 Fully responsive — Mobile, Tablet & Desktop
- 🎨 Premium financial/corporate design
- ⚡ Fast and lightweight
- 🧭 Smooth scrolling
- ✨ Modern animations and micro-interactions
- 📋 Online application form
- 📲 WhatsApp integration
- ☎️ Click-to-call phone integration
- ♿ Accessibility-friendly structure
- 🔍 SEO-friendly HTML structure
- 🖼️ Open Graph metadata
- 📦 No unnecessary dependencies
- 💾 Theme and language preferences stored with `localStorage`
- 🔌 Ready for backend, CRM and API integration

## 🛠️ Technologies

- **HTML5**
- **Tailwind CSS**
- **Vanilla JavaScript**
- **CSS3**
- **Web APIs**
- **WhatsApp URL API**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/babr-capital.git
```

Open the project:

```bash
cd babr-capital
```

Then open `index.html` in your browser.

No build process is required.

## 🌍 Language Support

The website supports:

- 🇹🇯 Tajik
- 🇷🇺 Russian

Users can switch languages directly from the header.

The selected language is saved in `localStorage`.

## 🌙 Theme System

The website includes:

- ☀️ Light Mode
- 🌙 Dark Mode

The selected theme is automatically saved using `localStorage`.

## 📲 WhatsApp Application

The online application form generates a structured WhatsApp message containing the user's:

- Name
- Phone number
- Message

The user is then redirected to WhatsApp to send the application.

> For production use, sensitive form processing should be moved to a secure backend/API instead of relying only on client-side JavaScript.
