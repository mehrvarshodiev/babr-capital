# Babr Capital Scroll Progress — Chrome Extension

Chrome does not allow extensions to draw inside the browser's own tab strip or address-bar UI. This extension therefore places a thin progress bar at the very top edge of the webpage viewport, visually separated from the site's content.

## Install locally
1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked**.
4. Select this `chrome-extension` folder.

The bar follows page scroll progress and works on normal webpages. Chrome internal pages (`chrome://...`) cannot be modified by extensions.
